UNDER THE HOOD

How it works

A fully local, open-source pipeline — no external AI APIs, no data leaves your machine.

01
CV Feature Extraction

21 explainable statistics — sharpness (Laplacian variance), brightness, contrast, noise estimate, saturation, entropy, blockiness, and more — are computed in milliseconds using NumPy and Pillow.

02
Deep Model Inference

A MobileNetV3-Small backbone (pretrained on ImageNet) fine-tuned with a dual-head architecture: a 6-class multi-label sigmoid classifier for issue detection, and a quality-score regression head. Trained on 15,479 real images from KADID-10k and MVTec AD.

03
Explainable Gate Override

If measured statistics exceed clear physical thresholds (e.g. brightness_mean < 0.18 for underexposure), the model probability is boosted to guarantee detection. This hybrid layer adds interpretability and catches cases where the model is uncertain.

04
Decision Policy

The quality score (0–100) is capped by detected issue confidence. Labels: ACCEPTABLE ≥ 70 with no medium/high issues; DEGRADED for reduced quality; POTENTIALLY_DEFECTIVE when the defect head fires above threshold.

KADID-10k 10,125 distorted images · 25 distortion types · quality regression + issue labels
MVTec AD 5,354 images · 15 industrial categories · defect detection head only
Known limitation Macro-F1 = 0.658 (target ≥ 0.70) — underexposure/overexposure classes are rare in KADID test set (4% positive rate). ROC-AUC for those classes is 0.88–0.91.
